Use your licensed Action Priority table

The AIAG-VDA Action Priority table is copyrighted and is not bundled here. If you have it, save it as a CSV with the header S,O,D,AP and one row per combination, then load it. Rows it does not cover fall back to the illustrative rule.

Why not RPN alone: S=10, O=2, D=5; S=2, O=5, D=10; and S=4, O=5, D=5 all give RPN 100, yet they are very different risks. The illustrative AP column weights severity first. Reduce severity only by design or process change; actions usually target occurrence or detection, then re-rate.
