A3 builder

Work the seven boxes in order. The checker looks for the things that make an A3 look finished without being any good: no numbers in the current condition, countermeasures written before any analysis, and no date to check the result.


Review

An A3 is a thinking document, not a form, and its value is in the conversation that produces it. The checker cannot judge whether your analysis is any good; it only catches the structural misses. Two rules it enforces as blockers: a current condition needs numbers, because without a measured starting point there is no gap and nothing to verify later; and countermeasures need a follow-up date, because an A3 closed without a check is a guess. Use this for a recurring problem whose cause is unclear. A customer escape wants an 8D instead, a small local fix wants kaizen, and a data-heavy variation problem wants DMAIC.
