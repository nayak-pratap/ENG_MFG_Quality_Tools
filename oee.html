OEE, takt and flow calculators

Four short calculators: OEE with loss breakdown, takt and line balance, Little's Law, and queue time from utilization.

1. OEE

Availability = run time / planned time. Performance = ideal cycle time x total units / run time. Quality = good / total. Count planned stops (breaks, planned maintenance) outside planned time, and record micro-stops as downtime, or OEE will look better than the process is. About 85% is often quoted as world-class for high-volume discrete work; many plants sit nearer 60 to 75%, and food, pharma and high-mix plants often run lower by design. Compare to your own baseline first.

2. Takt time and line balance

Takt = available time / demand. Minimum stations = ceil(total work / takt). Any single task longer than takt must be split or duplicated; balancing cannot fix it.

3. Little's Law

WIP = throughput x lead time. Fill exactly two boxes.

Use consistent time units. It holds for any stable system on average, so a WIP cut shortens lead time only if throughput holds.

4. Queue time from utilization (Kingman)

Wq = ((CVa² + CVs²) / 2) x (u / (1 - u)) x process time. An approximation for one machine; it shows why queues explode as utilization nears 100% and why variability matters as much as capacity.
